10.1

Figures and Axes

In Matplotlib, plots are built on a Figure (the canvas) containing one or more Axes (the actual plots).

Key Concepts

Figure: The entire window/canvas. Axes: An individual plot with its own coordinate system. Axis: The x or y axis with ticks and labels.

import matplotlib.pyplot as plt
import numpy as np

# Create figure and axes
fig, ax = plt.subplots()

# Plot on the axes
x = np.linspace(0, 10, 100)
ax.plot(x, np.sin(x))
plt.show()

Multiple Subplots

# Create 2x2 grid of subplots
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

axes[0, 0].plot(x, np.sin(x))
axes[0, 1].plot(x, np.cos(x))
axes[1, 0].plot(x, np.tan(x))
axes[1, 1].plot(x, x**2)

plt.tight_layout()  # Prevent overlapping
plt.show()
Object-Oriented vs Pyplot

Pyplot style: plt.plot(x, y) - Quick and simple.
OO style: ax.plot(x, y) - More control, recommended for complex plots.

10.2

Line Plots

Line plots connect data points with lines - ideal for showing trends over time or continuous data.

fig, ax = plt.subplots(figsize=(10, 6))

x = np.linspace(0, 10, 100)

# Multiple lines with styling
ax.plot(x, np.sin(x), label='sin(x)', color='blue', linewidth=2)
ax.plot(x, np.cos(x), label='cos(x)', color='red', linestyle='--')

# Add labels and title
ax.set_xlabel('X axis')
ax.set_ylabel('Y axis')
ax.set_title('Trigonometric Functions')
ax.legend()
ax.grid(True, alpha=0.3)

plt.show()

10.3

Customization

Make your plots publication-ready with titles, labels, legends, and annotations.

fig, ax = plt.subplots(figsize=(10, 6))

ax.plot(x, y)

# Titles and labels
ax.set_title('Stock Price Over Time', fontsize=16, fontweight='bold')
ax.set_xlabel('Date', fontsize=12)
ax.set_ylabel('Price ($)', fontsize=12)

# Axis limits
ax.set_xlim(0, 100)
ax.set_ylim(0, 500)

# Add annotation
ax.annotate('Peak!', xy=(50, 400), xytext=(60, 450),
            arrowprops=dict(arrowstyle='->'))

# Save to file
fig.savefig('my_plot.png', dpi=300, bbox_inches='tight')
📝’¡ Saving Plots

Use savefig() with dpi=300 for print quality. Supported formats: PNG, PDF, SVG, JPG.

10.4

Bar Charts & Histograms

Bar charts compare categorical data. Histograms show distribution of continuous data.

Bar Charts

categories = ['A', 'B', 'C', 'D']
values = [25, 40, 30, 55]

fig, ax = plt.subplots()
ax.bar(categories, values, color='steelblue')
ax.set_ylabel('Sales')
ax.set_title('Sales by Category')

# Horizontal bar chart
ax.barh(categories, values)

Histograms

data = np.random.randn(1000)  # Normal distribution

fig, ax = plt.subplots()
ax.hist(data, bins=30, color='steelblue', edgecolor='white', alpha=0.7)
ax.set_xlabel('Value')
ax.set_ylabel('Frequency')
ax.set_title('Distribution of Values')
Pandas Integration 
# Plot directly from DataFrame
df['column'].plot.hist(bins=20)
df.plot.bar(x='category', y='value')
10.5

Scatter Plots

Scatter plots reveal relationships between two variables. Great for correlation analysis!

x = np.random.randn(100)
y = 2 * x + np.random.randn(100) * 0.5
sizes = np.abs(np.random.randn(100)) * 100
colors = np.random.randn(100)

fig, ax = plt.subplots(figsize=(8, 6))
scatter = ax.scatter(x, y, s=sizes, c=colors, cmap='viridis', alpha=0.6)

# Add colorbar
plt.colorbar(scatter, label='Color Value')

ax.set_xlabel('X Variable')
ax.set_ylabel('Y Variable')
ax.set_title('Scatter Plot with Size and Color')

Seaborn Statistical Plots

Seaborn builds on Matplotlib with beautiful defaults and high-level statistical visualization functions.

import seaborn as sns

# Set the aesthetic style
sns.set_style('whitegrid')

# Load example dataset
tips = sns.load_dataset('tips')

# Bar plot with automatic confidence intervals
sns.barplot(x='day', y='total_bill', data=tips)

# Box plot
sns.boxplot(x='day', y='total_bill', hue='smoker', data=tips)

# Scatter with regression line
sns.regplot(x='total_bill', y='tip', data=tips)

# Pair plot for all numeric columns
sns.pairplot(tips, hue='smoker')

# Heatmap for correlation
sns.heatmap(tips.corr(), annot=True, cmap='coolwarm')
Seaborn Advantage

Seaborn integrates directly with Pandas DataFrames. Just pass column names as strings and the data parameter!

10.7

Styling & Themes

Transform your plots from default to professional with built-in themes and color palettes.

Seaborn Styles

# Available styles: darkgrid, whitegrid, dark, white, ticks
sns.set_style('whitegrid')

# Context scales: paper, notebook, talk, poster
sns.set_context('talk')  # Larger fonts for presentations

Color Palettes

# Built-in palettes: deep, muted, pastel, bright, dark, colorblind
sns.set_palette('colorblind')

# Custom palette
custom_colors = ['#0b2fa0', '#ff9000', '#10b981']
sns.set_palette(custom_colors)

# Matplotlib style sheets
plt.style.use('seaborn-v0_8')
plt.style.use('ggplot')
Professional Tips

Use 'colorblind' palette for accessibility. Set set_context('talk') for presentations. Always include axis labels and titles!

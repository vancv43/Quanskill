5.1

Creating Python Strings

A string is a sequence of characters enclosed in quotes. Python strings are one of the most fundamental data types, used extensively for storing and manipulating text data.

Definition: String

A string is an ordered sequence of characters (letters, numbers, symbols, spaces) enclosed in quotes. In Python, strings are objects of the built-in str class. Unlike some languages, Python has no separate "character" type - a single character is just a string of length 1.

Three Ways to Create Strings

Single Quotes
'Hello, World!'

Most common for short strings

Double Quotes
"Hello, World!"

Use when string contains '

Triple Quotes
"""Multi-line
string"""

For multi-line text & docstrings

# Single quotes
greeting = 'Hello, Python!'

# Double quotes (identical to single)
message = "Welcome to Quanskill"

# Double quotes when string contains apostrophe
sentence = "It's a beautiful day!"

# Single quotes when string contains double quotes
quote = 'She said "Hello" to everyone.'

# Triple quotes for multi-line strings
paragraph = """This is a multi-line string.
It can span several lines.
Very useful for documentation!"""

print(paragraph)
# Output:
# This is a multi-line string.
# It can span several lines.
# Very useful for documentation!

print(path)  # C:\Users\Documents\file.txt

5.2

String Immutability

Python strings are immutable, meaning once created, they cannot be changed. Any operation that appears to modify a string actually creates a new string.

Key Concept: Immutability

Immutable means the object's content cannot be altered after creation. You cannot change individual characters in a string - you must create a new string instead. This makes strings safer to use as dictionary keys and in multi-threaded programs.

# Attempting to modify a string character
text = "Hello"

# This will cause an ERROR!
# text[0] = "J"  # TypeError: 'str' object does not support item assignment

# Instead, create a NEW string
new_text = "J" + text[1:]
print(new_text)  # "Jello"

# Or use replace()
new_text = text.replace("H", "J")
print(new_text)  # "Jello"

# Original string is unchanged!
print(text)  # "Hello"
âš  Memory Consideration

Because strings are immutable, repeated concatenation in loops creates many temporary strings, which is inefficient. For building large strings, use join() or StringIO instead:

# âŒ Inefficient - creates new string each iteration
result = ""
for word in ["Hello", "World", "Python"]:
    result += word + " "

# âœ… Efficient - single operation
words = ["Hello", "World", "Python"]
result = " ".join(words)

Positive Indexing

text = "PYTHON"

# Access individual characters
print(text[0])  # 'P' - first character
print(text[1])  # 'Y' - second character
print(text[5])  # 'N' - last character

# Index out of range causes error
# print(text[6])  # IndexError!

Negative Indexing

Negative indices count from the end, making it easy to access the last characters:

text = "PYTHON"

# Negative indexing (from the end)
print(text[-1])  # 'N' - last character
print(text[-2])  # 'O' - second to last
print(text[-6])  # 'P' - first character

# Useful for getting file extensions
filename = "report.pdf"
extension = filename[-3:]  # "pdf"
Data Science Tip

Negative indexing is especially useful when working with file paths, URLs, or any strings where you need the ending portion regardless of total length.

5.4

String Slicing

Slicing extracts a substring using the syntax string[start:stop:step]. The slice includes the start index but excludes the stop index.

Slicing Syntax
string[start:stop:step]

# start: index where slice begins (default: 0)
# stop:  index where slice ends (exclusive, default: len)
# step:  increment between indices (default: 1)
text = "PYTHON PROGRAMMING"

# Basic slicing [start:stop]
print(text[0:6])   # "PYTHON" (indices 0-5)
print(text[7:18])  # "PROGRAMMING"

# Omitting start or stop
print(text[:6])    # "PYTHON" (from beginning)
print(text[7:])    # "PROGRAMMING" (to end)
print(text[:])     # "PYTHON PROGRAMMING" (copy)

# Using step
print(text[::2])   # "PTO RGAMN" (every 2nd char)
print(text[0:6:2]) # "PTO" (every 2nd in "PYTHON")

# Negative step (reverse)
print(text[::-1])  # "GNIMMARGORP NOHTYP" (reversed!)

5.5

String Operations

Python provides operators for combining, repeating, and testing strings.

Concatenation (+)

Join two or more strings together:

# String concatenation
first = "Hello"
second = "World"

combined = first + " " + second
print(combined)  # "Hello World"

# Building strings
name = "Alice"
greeting = "Welcome, " + name + "!"
print(greeting)  # "Welcome, Alice!"

Repetition (*)

Repeat a string multiple times:

# String repetition
dash = "-" * 20
print(dash)  # "--------------------"

pattern = "AB" * 5
print(pattern)  # "ABABABABAB"

# Creating visual separators
header = "=" * 40
print(header)
print("    DATA SCIENCE REPORT")
print(header)

Membership (in / not in)

Check if a substring exists within a string:

text = "Python is amazing for data science"

# Check membership
print("Python" in text)      # True
print("python" in text)      # False (case-sensitive!)
print("Java" not in text)    # True
print("data" in text)        # True

# Practical use: validation
email = "[email protected]"
if "@" in email:
    print("Valid email format")

Comparison

Compare strings lexicographically (dictionary order):

# Equality
print("hello" == "hello")  # True
print("hello" == "Hello")  # False (case matters)
print("hello" != "world")  # True

# Lexicographic comparison
print("apple" < "banana")   # True (a comes before b)
print("Apple" < "apple")   # True (uppercase < lowercase)

5.6

String Methods

Python strings have many built-in methods for transformation, searching, and manipulation. Methods are called using dot notation: string.method().

Case Methods

.upper()

Convert to uppercase

"hello".upper() ←’ "HELLO"
.lower()

Convert to lowercase

"HELLO".lower() ←’ "hello"
.title()

Capitalize each word

"hello world".title() ←’ "Hello World"
.capitalize()

Capitalize first letter

"hello".capitalize() ←’ "Hello"
.swapcase()

Swap upper/lower

"Hello".swapcase() ←’ "hELLO"

Search Methods

text = "Python is powerful. Python is popular."

# find() - returns index of first occurrence (-1 if not found)
print(text.find("Python"))   # 0
print(text.find("is"))       # 7
print(text.find("Java"))     # -1 (not found)

# rfind() - search from the right
print(text.rfind("Python"))  # 20 (last occurrence)

# count() - count occurrences
print(text.count("Python"))  # 2
print(text.count("is"))      # 2

# startswith() / endswith()
print(text.startswith("Python"))  # True
print(text.endswith("."))        # True

Modification Methods

# replace() - replace substring
text = "I love Java"
new_text = text.replace("Java", "Python")
print(new_text)  # "I love Python"

# strip() - remove whitespace from both ends
messy = "   Hello World   "
print(messy.strip())   # "Hello World"
print(messy.lstrip())  # "Hello World   " (left only)
print(messy.rstrip())  # "   Hello World" (right only)

# split() - split into list
sentence = "Python is awesome"
words = sentence.split()  # Split by whitespace
print(words)  # ['Python', 'is', 'awesome']

csv_data = "apple,banana,cherry"
fruits = csv_data.split(",")  # Split by comma
print(fruits)  # ['apple', 'banana', 'cherry']

# join() - join list into string
words = ["Python", "is", "fun"]
sentence = " ".join(words)
print(sentence)  # "Python is fun"

String Formatting

Python offers several ways to embed variables and expressions inside strings. The modern f-string syntax (Python 3.6+) is the most readable and efficient.

f-Strings (Recommended)

Prefix with f and use {} for expressions:

name = "Alice"
age = 28
score = 95.678

# Basic f-string
print(f"Hello, {name}!")  # Hello, Alice!
print(f"{name} is {age} years old.")

# Expressions inside braces
print(f"Next year, {name} will be {age + 1}.")

# Formatting numbers
print(f"Score: {score:.2f}")    # Score: 95.68 (2 decimals)
print(f"Score: {score:>10.2f}")  # Right-aligned, width 10

# Percentage
ratio = 0.857
print(f"Accuracy: {ratio:.1%}")  # Accuracy: 85.7%

# Large numbers with commas
population = 8500000
print(f"Population: {population:,}")  # Population: 8,500,000

format() Method

# Using .format()
template = "Hello, {}! You scored {}%"
print(template.format("Bob", 92))

# Named placeholders
template = "Dear {name}, your order #{order_id} is ready."
print(template.format(name="Alice", order_id=1234))

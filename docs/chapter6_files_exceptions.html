6.1

Opening Files

Python's built-in open() function is the gateway to file operations. It returns a file object that you can use to read, write, or manipulate file contents.

The open() Function

The open() function opens a file and returns a file object. It takes a file path and a mode string that determines how the file will be accessed (read, write, append, etc.).

Basic Syntax
file_object = open(filename, mode="r", encoding="utf-8")

# filename: path to the file (relative or absolute)
# mode: how to open the file (default: "r" for read)
# encoding: character encoding (recommended: "utf-8")

File Modes

"r"

Read only (default)

"w"

Write (overwrites!)

"a"

Append to end

"r+"

Read and write

"x"

Create new (fails if exists)

"rb"

Read binary

Mode Description File Must Exist? Creates File?
"r"Read onlyYesNo
"w"Write (overwrites existing content)NoYes
"a"Append to end of fileNoYes
"x"Exclusive create (fails if exists)NoYes
"r+"Read and writeYesNo
"b"Binary mode (add to other modes)--
 
# Open a file for reading
f = open("data.txt", "r", encoding="utf-8")

# Always close when done!
f.close()

# Open for writing (creates file or overwrites)
f = open("output.txt", "w", encoding="utf-8")
f.close()

# Open for appending (adds to end)
f = open("log.txt", "a", encoding="utf-8")
f.close()
âš  Always Specify Encoding

The default encoding varies by operating system. For consistent behavior, always specify encoding="utf-8" when opening text files. This prevents issues when sharing code across different platforms.

6.2

Reading Files

Python provides multiple methods to read file contents, depending on whether you need the entire file, one line, or all lines as a list.

Reading Methods

Method Returns Use Case
read()Entire file as one stringSmall files
read(n)First n charactersReading in chunks
readline()One line at a timeProcessing line by line
readlines()List of all linesWhen you need all lines
 
# Method 1: read() - entire file as string
f = open("poem.txt", "r", encoding="utf-8")
content = f.read()
print(content)
f.close()

# Method 2: read(n) - first n characters
f = open("poem.txt", "r", encoding="utf-8")
first_10 = f.read(10)  # Read first 10 characters
print(first_10)
f.close()

# Method 3: readline() - one line at a time
f = open("poem.txt", "r", encoding="utf-8")
line1 = f.readline()  # First line
line2 = f.readline()  # Second line
f.close()

# Method 4: readlines() - list of all lines
f = open("poem.txt", "r", encoding="utf-8")
lines = f.readlines()  # ['line1\n', 'line2\n', ...]
f.close()

Iterating Over Lines

The most memory-efficient way to process a file line by line is to iterate directly over the file object:

# Best practice: iterate directly over file
f = open("data.txt", "r", encoding="utf-8")
for line in f:
    print(line.strip())  # strip() removes \n
f.close()

# Clean way using list comprehension
f = open("data.txt", "r", encoding="utf-8")
clean_lines = [line.strip() for line in f]
f.close()
print(clean_lines)  # List without newline characters
Data Science Example: Reading CSV Manually 
# Reading a simple CSV file
f = open("students.csv", "r", encoding="utf-8")

# Skip header
header = f.readline().strip().split(",")
print(f"Columns: {header}")

# Process data rows
for line in f:
    name, age, grade = line.strip().split(",")
    print(f"{name} is {age} years old with grade {grade}")

f.close()
6.3

Writing Files

Writing to files allows you to save data, generate reports, and create output for other programs. Be careful with "w" mode - it will overwrite existing content!

Writing Methods

Method Description Example
write(string)Write a string to filef.write("Hello")
writelines(list)Write list of stringsf.writelines(lines)
 
# Writing with "w" mode (creates/overwrites)
f = open("output.txt", "w", encoding="utf-8")
f.write("Hello, World!\n")
f.write("Welcome to Python.\n")
f.close()

# Writing multiple lines with writelines()
lines = ["Line 1\n", "Line 2\n", "Line 3\n"]
f = open("output.txt", "w", encoding="utf-8")
f.writelines(lines)
f.close()

# Appending with "a" mode (adds to end)
f = open("log.txt", "a", encoding="utf-8")
f.write("New log entry\n")
f.close()
âš  Important: write() Doesn't Add Newlines

Unlike print(), the write() method does not automatically add newline characters. You must include \n explicitly if you want line breaks.

Data Science Example: Saving Results 
# Save analysis results to file
results = {
    "mean": 85.5,
    "median": 88.0,
    "std_dev": 12.3
}

f = open("analysis_report.txt", "w", encoding="utf-8")
f.write("=== Analysis Report ===\n\n")
for metric, value in results.items():
    f.write(f"{metric}: {value}\n")
f.write("\nReport generated successfully.")
f.close()
6.4

The with Statement (Context Managers)

The with statement is the recommended way to work with files. It automatically closes the file when you're done, even if an error occurs.

Context Manager

A context manager handles setup and cleanup automatically. When you use with open(), Python guarantees the file will be closed when the block ends, preventing resource leaks and data corruption.

File Handling Flow
📝‚ Open File
←’
🐍" Read/Write
←’
🔍’ Close File

The with statement handles Open and Close automatically!

# âœ… RECOMMENDED: Using 'with' statement
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
# File is automatically closed here!

# Reading lines with 'with'
with open("data.txt", "r", encoding="utf-8") as f:
    lines = [line.strip() for line in f]

# Writing with 'with'
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello, World!\n")
    f.write("Goodbye!\n")
# File is automatically closed and saved!

Multiple Files

# Working with multiple files simultaneously
with open("input.txt", "r") as infile, open("output.txt", "w") as outfile:
    for line in infile:
        # Process and write each line
        processed = line.upper()
        outfile.write(processed)
# Both files closed automatically!
Why Use with?
  • Automatic Cleanup: File is closed even if an error occurs
  • Cleaner Code: No need for explicit close() calls
  • Prevents Bugs: Avoids forgetting to close files
  • Resource Safety: Prevents file handle leaks

6.5

Exception Handling with try/except

Errors happen. Files may not exist, data may be corrupt, or users may enter invalid input. Exception handling lets your program respond gracefully instead of crashing.

What is an Exception?

An exception is an error that occurs during program execution. Without handling, exceptions crash your program. The try/except block lets you catch exceptions and respond appropriately.

try/except Syntax
try:
    # Code that might raise an exception
    risky_operation()
except ExceptionType:
    # Code to handle the exception
    handle_error()
# Without exception handling - CRASH!
# result = 10 / 0  # ZeroDivisionError!

# With exception handling - graceful recovery
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Error: Cannot divide by zero!")
    result = 0

print(f"Result: {result}")  # Program continues!

File Operations with Exception Handling

# Safe file reading
try:
    with open("data.txt", "r") as f:
        content = f.read()
        print(content)
except FileNotFoundError:
    print("Error: File not found!")
except PermissionError:
    print("Error: No permission to read file!")

Catching Multiple Exceptions

# Method 1: Multiple except blocks
try:
    value = int(input("Enter a number: "))
    result = 100 / value
except ValueError:
    print("Invalid input! Please enter a number.")
except ZeroDivisionError:
    print("Cannot divide by zero!")

# Method 2: Tuple of exception types
try:
    value = int(input("Enter a number: "))
    result = 100 / value
except (ValueError, ZeroDivisionError) as e:
    print(f"Error occurred: {e}")
Getting Error Details

Use as e to capture the exception object and access its message:

try:
    int("hello")
except ValueError as e:
    print(f"Error: {e}")
# Output: Error: invalid literal for int() with base 10: 'hello'

Common Exception Types

Python has many built-in exception types. Knowing the common ones helps you write more specific error handling.

FileNotFoundError

File doesn't exist

ValueError

Wrong value type (e.g., int("abc"))

TypeError

Wrong data type for operation

ZeroDivisionError

Division by zero

IndexError

List index out of range

KeyError

Dictionary key not found

PermissionError

No file access permission

AttributeError

Object has no attribute

# Examples of common exceptions

# ValueError
try:
    num = int("hello")
except ValueError:
    print("Cannot convert 'hello' to integer")

# IndexError
try:
    items = [1, 2, 3]
    print(items[10])
except IndexError:
    print("Index out of range!")

# KeyError
try:
    data = {"name": "Alice"}
    print(data["age"])
except KeyError:
    print("Key 'age' not found in dictionary")
Data Science: Safe Data Conversion 
def safe_float(value):
    """Convert to float, return None if invalid."""
    try:
        return float(value)
    except (ValueError, TypeError):
        return None

# Process messy data
raw_data = ["42.5", "N/A", "31.2", "", "28.9"]
clean_data = [safe_float(x) for x in raw_data]
print(clean_data)  # [42.5, None, 31.2, None, 28.9]

# Filter out None values
valid_data = [x for x in clean_data if x is not None]
print(valid_data)  # [42.5, 31.2, 28.9]
6.7

finally and else Clauses

The finally and else clauses give you more control over exception handling flow.

The finally Clause

finally runs always - whether an exception occurred or not. Use it for cleanup code that must execute.

try:
    f = open("data.txt", "r")
    content = f.read()
    print(content)
except FileNotFoundError:
    print("File not found!")
finally:
    print("Cleanup: Closing resources...")
    # This ALWAYS runs, error or not
    if 'f' in dir():
        f.close()

The else Clause

else runs only if no exception occurred in the try block:

try:
    num = int(input("Enter a number: "))
except ValueError:
    print("That's not a valid number!")
else:
    # Only runs if no exception
    print(f"You entered: {num}")
    print(f"Doubled: {num * 2}")

Complete Structure

try:
    # Risky operation
    result = perform_operation()
except SomeError:
    # Handle specific error
    handle_error()
else:
    # Success! No exceptions raised
    process_result(result)
finally:
    # Always runs - cleanup
    cleanup()
Clause When It Runs Use Case
try Always (first) Code that might raise exception
except Only if exception occurs Error handling
else Only if NO exception Success-only code
finally Always (last) Cleanup (close files, connections)
Quick Check

In what order do the clauses execute if NO exception occurs?

try ←’ except ←’ finally
try ←’ else ←’ finally
try ←’ finally ←’ else
try only
Correct! When no exception occurs: try runs, except is skipped, else runs, then finally runs.
Remember: else only runs if there's NO exception; finally always runs last.

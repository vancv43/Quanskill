What is Python?

Python is a high-level, interpreted, object-oriented programming language with dynamic semantics. Its clear syntax and emphasis on readability make it an ideal first language for beginners while remaining powerful enough for experts.

Definition: Python

Python is a versatile programming language created by Guido van Rossum in the late 1980s. Named after the British comedy group "Monty Python," it emphasizes code readability and allows programmers to express concepts in fewer lines of code than languages like C++ or Java.

Why Python for Data Science?

Python has become the #1 language for data science for several compelling reasons:

  • Easy to Learn: Simple, English-like syntax reduces the learning curve
  • Rich Ecosystem: Powerful libraries like NumPy, Pandas, and Scikit-learn
  • Community Support: Massive global community with extensive documentation
  • Versatility: Works for web development, automation, AI, and more
  • Industry Adoption: Used by Google, Netflix, NASA, and countless startups

Variables and Data Types

Variables are fundamental building blocks in programming. In Python, a variable is a named memory location that stores a value. Unlike some languages, Python determines the variable type automatically based on the assigned value.

Definition: Variable

A variable is a container for storing data values. In Python, you don't need to declare a variable's type explicitly - Python infers it from the value you assign. The equal sign (=) is the assignment operator.

Creating Variables

# Variable assignment in Python
name = "Quanskill"        # String variable
age = 25                   # Integer variable
price = 19.99              # Float variable
is_enrolled = True        # Boolean variable

# Print variables
print(name)                # Output: Quanskill
print(age)                 # Output: 25
print(price)               # Output: 19.99

Python Data Types

Python has several built-in data types to handle different kinds of data:

Sequence list, tuple Ordered collections [1,2,3], (1,2,3)
Mapping dict Key-value pairs {"name": "John"}

Working with Numbers

# Integer operations
x = 20
y = 5

print(x + y)    # Addition: 25
print(x - y)    # Subtraction: 15
print(x * y)    # Multiplication: 100
print(x / y)    # Division: 4.0

# Float operations
price = 4.67
print(price * 3)  # Output: 14.01

Working with Strings

# String creation and operations
greeting = "Happy"
print(greeting)           # Output: Happy
print(greeting[0])        # First character: H
print(greeting + " Morning")  # Concatenation: Happy Morning
print(len(greeting))      # Length: 5

Python Operators

Operators are special symbols that perform operations on values and variables. They form the foundation of expressions used to work with data and perform calculations.

Arithmetic Operators

Operator Description Example Result
+ Addition 10 + 5 15
- Subtraction 10 - 5 5
* Multiplication 10 * 5 50
/ Division 10 / 5 2.0
% Modulus (remainder) 10 % 3 1
** Exponent 2 ** 3 8
// Floor Division 10 // 3 3

Comparison Operators

Comparison operators compare values and return True or False:

x = 10
y = 5

print(x == y)   # Equal: False
print(x != y)   # Not Equal: True
print(x > y)    # Greater Than: True
print(x < y)    # Less Than: False
print(x >= y)   # Greater or Equal: True
print(x <= y)   # Less or Equal: False

Assignment Operators

# Basic assignment
x = 20

# Compound assignment operators
x += 5     # Same as: x = x + 5  ←’ x is now 25
x -= 3     # Same as: x = x - 3  ←’ x is now 22
x *= 2     # Same as: x = x * 2  ←’ x is now 44
x /= 4     # Same as: x = x / 4  ←’ x is now 11.0
Real-World Application

In data science, operators are essential for:

  • Data Cleaning: Comparing values to identify outliers
  • Feature Engineering: Creating new variables from existing data
  • Statistical Calculations: Computing means, sums, and percentages
  • Model Evaluation: Comparing predictions to actual values

9.1

The Pandas Series

A Series is a one-dimensional labeled array that can hold any data type. Think of it as a column in a spreadsheet with an index.

What is Pandas?

Pandas is designed for working with tabular and heterogeneous data. While NumPy excels at homogeneous numerical arrays, Pandas handles real-world messy data with labeled axes.

import pandas as pd
import numpy as np

# Create a Series from a list
s = pd.Series([10, 20, 30, 40])
print(s)
# 0    10
# 1    20
# 2    30
# 3    40
# dtype: int64

# Series with custom index
s = pd.Series([100, 200, 300], index=['a', 'b', 'c'])
print(s['b'])  # 200
Series from Dictionary 
population = pd.Series({
    'California': 39538223,
    'Texas': 29145505,
    'Florida': 21538187
})
print(population['Texas'])  # 29145505
9.2

The DataFrame

A DataFrame is a two-dimensional table with labeled rows and columns. It's the most commonly used Pandas object.

DataFrame Structure

Think of a DataFrame as a dictionary of Series sharing the same index, or as a spreadsheet/SQL table with rows and columns.

# Create DataFrame from dictionary
data = {
    'Name': ['Alice', 'Bob', 'Carol'],
    'Age': [25, 30, 35],
    'City': ['NYC', 'LA', 'Chicago']
}
df = pd.DataFrame(data)
print(df)

print(df['Name'])      # Returns Series
print(df.Age)          # Attribute access

# DataFrame properties
print(df.shape)        # (3, 3)
print(df.columns)      # Index(['Name', 'Age', 'City'])
print(df.dtypes)       # Data types of each column
9.3

Indexing & Selection

Pandas provides powerful ways to select and filter data using loc (label-based) and iloc (integer-based).

# loc: Label-based indexing
df.loc[0]              # First row
df.loc[0, 'Name']      # 'Alice'
df.loc[0:1, ['Name', 'Age']]  # Slice rows and columns

# iloc: Integer-based indexing
df.iloc[0]             # First row
df.iloc[0, 1]          # Row 0, Column 1
df.iloc[:2, :2]        # First 2 rows, first 2 columns

# Boolean indexing
df[df['Age'] > 25]     # Rows where Age > 25
âš  loc vs iloc

loc uses labels (inclusive on both ends). iloc uses integer positions (exclusive on the end, like Python slicing).

Quick Check

Reading Data

Pandas can read data from many file formats. The most common is CSV.

read_csv()

CSV files

pd.read_csv('data.csv')
read_excel()

Excel files

pd.read_excel('data.xlsx')
read_json()

JSON files

pd.read_json('data.json')
read_sql()

SQL databases

pd.read_sql(query, conn)
# Read CSV file
df = pd.read_csv('sales_data.csv')

# Common parameters
df = pd.read_csv('data.csv',
    index_col='id',           # Set column as index
    parse_dates=['date'],      # Parse date columns
    na_values=['NA', '?'],     # Custom NA values
    nrows=1000                 # Read only first 1000 rows
)

# Quick data inspection
df.head()        # First 5 rows
df.tail()        # Last 5 rows
df.info()        # Column types and non-null counts
df.describe()    # Statistical summary

9.6

Handling Missing Data

Real-world data is messy. Pandas represents missing values as NaN (Not a Number) or None.

# Detect missing values
df.isna()         # Boolean mask of NaN values
df.isna().sum()   # Count NaN per column

# Drop missing values
df.dropna()                  # Drop rows with any NaN
df.dropna(how='all')         # Drop rows where ALL are NaN
df.dropna(axis='columns')    # Drop columns with NaN
df.dropna(thresh=2)          # Keep rows with at least 2 non-NaN

# Fill missing values
df.fillna(0)                  # Fill with constant
df.fillna(df.mean())          # Fill with column means
df.fillna(method='ffill')    # Forward fill
df.fillna(method='bfill')    # Backward fill
Data Cleaning Example 
# Fill different columns with different values
df.fillna({'Age': df['Age'].median(), 'City': 'Unknown'})
9.7

Data Transformation

Transform and reshape your data for analysis.

# Add new columns
df['Bonus'] = df['Salary'] * 0.1

# Apply functions
df['Name'].apply(lambda x: x.upper())
df['Age'].apply(np.sqrt)

# Replace values
df.replace({'NYC': 'New York', 'LA': 'Los Angeles'})

# Remove duplicates
df.drop_duplicates()
df.drop_duplicates(subset=['Name'])  # Based on specific columns

# Rename columns
df.rename(columns={'Name': 'FullName', 'Age': 'Years'})

# Sort values
df.sort_values('Age', ascending=False)
9.8

GroupBy Operations

The split-apply-combine pattern is fundamental to data analysis. GroupBy splits data into groups, applies a function, then combines results.

Split-Apply-Combine

Split: Divide data by key. Apply: Compute function per group. Combine: Merge results into one object.

# Sample data
df = pd.DataFrame({
    'Department': ['Sales', 'Sales', 'IT', 'IT', 'HR'],
    'Employee': ['Alice', 'Bob', 'Carol', 'Dave', 'Eve'],
    'Salary': [70000, 80000, 90000, 85000, 60000]
})

# Group and aggregate
df.groupby('Department')['Salary'].mean()
# Department
# HR       60000.0
# IT       87500.0
# Sales    75000.0

# Multiple aggregations
df.groupby('Department').agg({
    'Salary': ['mean', 'sum', 'count']
})
